# Syllabus notes (stand-in until the official syllabus is added)

Source: the project brief given to the build team, plus the public course
catalogue description of PRV 201 "Frontiers of Technology: A.I. and Machine
Learning" (Stevens Institute of Technology academic catalogue, 2024-2025), which
describes an interdisciplinary survey of AI applications (autonomous
transportation, fraud detection, natural language processing, hybrid human-AI
systems, face recognition) with attention to fairness, accountability,
transparency, ethics, safety and the law.

## Milestones and points (from the brief)

| Milestone | Points |
|---|---|
| M1 - Problem statement | 25 |
| M2 - Design / approach | 45 |
| M3 - Prototype / draft | 64 |
| M4 - Peer review | 22 |
| M5 - Demo Day / capstone | 84 |

Due-date rule: work listed in a week is due by the start of the following class.

## Grading process (from the brief)

- Each milestone is graded once as a team, then individually. The team splits
  each milestone into as many parts as it has members; each student leads and
  signs one part. A member earns 100 % of the team score for a full, meaningful
  part, 50 % for a partial or thin part and 0 % if it is missing.
- An LLM preliminary reader scores each submission after names and emails are
  stripped; large LLM/human score disagreements are flagged automatically.
- Using AI to build the project is the explicit point of the course.
